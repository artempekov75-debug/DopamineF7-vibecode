# DopamineF7 (vibecode)

Минималистичный системный твикер, деблоатер и монитор телеметрии в реальном времени для **POCO F7 (HyperOS)**, работающий без Root-прав через **Shizuku**.  
*Проект написан и скомпилирован с нуля прямо на смартфоне в AndroidIDE (pure vibecode).*

## Основные возможности
* **Live Telemetry:** мониторинг загрузки CPU (`%`), частот производительных ядер и занятой оперативной памяти (RAM) в реальном времени.
* **System Tweaks & Debloat:** отключение системных рекомендаций, аналитики и рекламных служб HyperOS (`msa`, `analytics`, `daemon`).
* **Display Control:** принудительная фиксация **120 Гц** и ускорение системных анимаций (`0.5x`).
* **Restore Point:** создание резервной точки отката настроек и быстрый возврат к стоковым параметрам (`1.0x / Auto Hz`).
* **Battery Care:** отслеживание точного заряда, температуры и вольтажа батареи.
* **App Manager:** управление установленными пользовательскими пакетами с возможностью заморозки (`FREEZE`) и разморозки (`ENABLE`).
* **Log Viewer:** встроенная консоль со статусами выполнения каждой системной команды (`[SUCCESS]` / `[FAILED]`).

## Установка и запуск
1. Скачай актуальный `.apk` из раздела **[Releases](../../releases)** и установи на смартфон.
2. Установи и запусти сервис **[Shizuku](https://rikka.app)** (через беспроводную отладку).
3. Открой **DopamineF7** и предоставь доступ к Shizuku.

## Технологический стек
* **Язык и UI:** Kotlin + Jetpack Compose (Material 3)
* **Привилегированный доступ:** Shizuku API 13.1.5 (`UserService` поверх прямого `IBinder`)
* **Среда сборки:** AndroidIDE (на устройстве)
